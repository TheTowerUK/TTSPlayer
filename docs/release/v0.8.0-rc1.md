# TTSPlayer v0.8.0-rc.1 — Windows release candidate

Target: M7 Metadata Enrichment, from `m7-development`. This is a candidate for local validation; the stable release has not been published.

## What's included

- Optional, explicitly enabled Open Library book metadata. Local files and catalogue remain authoritative.
- Search and candidate review, plus ISBN lookup that shows the returned book before saving a link.
- On-demand provider cover downloads. Cached artwork and linked metadata are retained when external metadata is turned off.
- Provider operation controls and a copyable, redacted diagnostics report.

Some successfully linked editions still show **Cover unavailable**. An ISBN match can succeed without a usable artwork reference.
