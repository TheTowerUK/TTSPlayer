# v0.7.0-dev — M6 development tracker

**Status:** Development — Phase 6.0 Planning and Architecture  
**Branch:** `m6-development`  
**App version:** remains `0.6.0+1` until an implementation phase bumps it  
**Predecessor release:** [v0.6.0](./v0.6.0.md) / [M5 complete](./m5-complete.md)

This is a **development tracker**, not a shipped release note. Do not treat M6 or any implementation phase as complete.

---

## Objective

Plan and (after agreement) implement **books and comics** reading on the folder-first TTSPlayer platform — see [m6-plan.md](../roadmap/m6-plan.md).

**Comic baseline (required):** `.cbz` and `.cbr` are both in M6 scope. CBR is an implementation/dependency risk, not optional product scope. Windows RAR/CBR solution selection is a Phase 6.0 or early 6.1 prerequisite. Comic reader DoD requires Windows runtime validation of both formats.

**Not in initial comic scope:** loose image folders as virtual comics (unless separately approved).
