---

## Objective

Plan and (after agreement) implement **books and comics** reading on the folder-first TTSPlayer platform — see [m6-plan.md](../roadmap/m6-plan.md).

**Comic baseline (required):** `.cbz` and `.cbr` are both in M6 scope. CBR/RAR approach in 6.1 is **provisional preferred** `package:unrar` (official UnRAR FFI) — **not** `package:rar` for Windows ([evaluation](../architecture/cbr-rar-evaluation.md)). Dependency deferred until Phase **6.3 Gate 0** passes. Comic reader DoD requires Windows runtime validation of both formats.

**Catalogue (6.1):** `catalogue_version: 4`, scanner `0.5.0`, kinds `book` / `comic`, extensions `.pdf` `.epub` `.cbz` `.cbr`.

**Not in initial comic scope:** loose image folders as virtual comics (unless separately approved).
