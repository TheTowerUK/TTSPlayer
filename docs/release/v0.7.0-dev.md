## Comic format (production)

**Supported:** `.cbz` (ZIP-based comic archive)  
**Not supported:** `.cbr` / RAR — convert externally to CBZ and rescan. See [ADR-026 Accepted](../architecture/decisions/ADR-026-reader-surface-architecture.md).

When a legacy CBR item appears in the catalogue, Open Comic is disabled and the app shows:

> CBR archives are not supported. Convert this comic to ZIP/CBZ and rescan the library.

**No UnRAR dependency** in runtime, packaging, or Release builds.

### Phase 6.4C — Comic reading experience closure ✅

**Status:** ✅ **Complete** (2026-07-28) — [m6-phase-6.4-comic-reading-experience.md](../roadmap/m6-phase-6.4-comic-reading-experience.md)

**Delivered:**

- Production CBZ reader UX: fit modes (Contain default, Fit Width/Height), keyboard/wheel/tap/swipe input, immersive chrome, zoom/pan contract
- Reading progress: save/restore, close flush, entry-name reconciliation, multi-page completion threshold, single-page completion-on-close, Read Again, Continue Reading exclusion
- Per-page error resilience: archive-level block, page placeholders, retry, preload isolation
- Redacted active-session diagnostics (`=== Comic reader ===`)
- Windows opt-in runtime validation: **Run 1:** 13 passed, 0 failed · **Run 2:** 13 passed, 0 failed
- Progress-session binding race fix when archive open completes before coordinator availability

**Validation (2026-07-28):** Flutter **3.44.4**, Dart **3.12.2**, Windows **10.0.26200**. Default suite: **1423 passed, 16 skipped**. Release build: ✅. No CBR/UnRAR tooling required.

**Accepted limitations:** wheel (C11) and fit height (C13) widget-automated under default test surface; post-corrupt forward navigation (C29) widget-automated; swipe restricted to Contain at base transform; no bookmarks/annotations/dual-page/RTL/cloud sync; CBR requires external conversion.
