## Objective

Plan and (after agreement) implement **books and comics** reading on the folder-first TTSPlayer platform — see [m6-plan.md](../roadmap/m6-plan.md).

**Comic baseline (required):** `.cbz` and `.cbr` remain in M6 scope. Gate 0 (2026-07-25) **failed** published `package:unrar` 0.1.2 on Windows MSVC native hooks — see [cbr-rar-evaluation.md](../architecture/cbr-rar-evaluation.md). Next: evaluate owned UnRAR FFI/DLL packaging or bundled UnRAR CLI. ADR-026 remains Proposed.

**Catalogue (6.1):** `catalogue_version: 4`, scanner `0.5.0`, kinds `book` / `comic`, extensions `.pdf` `.epub` `.cbz` `.cbr`.

**Browse (6.2):** Folder filters, kind badges, search kind chips, detail metadata + non-reader stub; no readers yet.

**Not in initial comic scope:** loose image folders as virtual comics (unless separately approved).
