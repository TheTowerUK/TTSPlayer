## Objective

Plan and implement **books and comics** reading on the folder-first TTSPlayer platform — see [m6-plan.md](../roadmap/m6-plan.md).

**Comic baseline (required):** `.cbz` and `.cbr`. Gate 0: `package:unrar` Fail; official UnRAR CLI **Conditional pass** — see [cbr-rar-evaluation.md](../architecture/cbr-rar-evaluation.md).

**Comic reader checkpoint (6.3):**

| Item | Status |
|---|---|
| CBZ | Fully implemented; runtime validated |
| CBR | Technically implemented; locally validated; production distribution **blocked** pending UnRAR approval |
| ADR-026 | **Proposed** (comic architecture provisionally validated) |
| Phase 6.3 DoD | **Not complete** while redistribution approval remains blocking |

**Catalogue (6.1):** `catalogue_version: 4`, scanner `0.5.0`, kinds `book` / `comic`, extensions `.pdf` `.epub` `.cbz` `.cbr`.

**Browse (6.2):** Folder filters, kind badges, search kind chips, detail metadata.

**Book reader (6.4):** ✅ **Complete** — PDF via `pdfrx`, EPUB via TTSPlayer parser + `flutter_html`; opt-in Windows harness validates ItemDetail → Open Book → PdfViewer render, page nav, zoom, close.

**Not in initial comic scope:** loose image folders as virtual comics (unless separately approved).

## Explicitly not in this tracker’s default scope

- M5 deferred music features (playlists, shuffle/repeat, lyrics, favourites redesign, etc.)

- Cloud metadata APIs / DRM formats
- Silent deferral of `.cbr` (any deferral requires explicit approval before M6 closure)
- Claiming production approval to redistribute `UnRAR.exe` without formal confirmation
- Closing Phase 6.3 while UnRAR redistribution approval remains blocking
