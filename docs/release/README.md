# Release

Shipping history and version notes for TTSPlayer.

- **[Release history](./release-history.md)** — changelog by version

When tagging a release:

1. Update `release-history.md` with Added / Changed / Fixed
2. Bump `client/ttsplayer/pubspec.yaml` version
3. Annotate git tag: `git tag -a vX.Y.Z -m "..."`
4. Update milestone status in [`../roadmap/roadmap.md`](../roadmap/roadmap.md)
