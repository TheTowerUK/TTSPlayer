# TTSPlayer v0.8.2 — M7 Metadata Enrichment

Windows x64, build 2 (`0.8.2+2`).

- Optional Open Library metadata for books, with manual match review and confirmation before saving ISBN links.
- On-demand cover downloads. Downloaded artwork and linked metadata are retained when External Metadata is turned off.
- Improved search and book details, with copyable diagnostics.
- Uncropped 2:3 cover artwork on video grids, reader-leaf folder cards, and Continue Watching and Continue Reading.
- A leaf folder with one playable video opens in the player; Details still opens the item screen.
- Video cards show cleaned display titles without changing catalogue filenames.
- Dashboard carousels (Continue Watching, Continue Reading, Recently Added, Featured Folders) page with labelled left and right controls.
- Continue Watching and Continue Reading rows can be removed without deleting saved progress; Undo and later progress can bring an item back.
- Playback stop no longer notifies after the player service has been disposed.
- Some linked editions may show Cover unavailable when there is no usable cover reference.
