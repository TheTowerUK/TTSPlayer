# TTSPlayer v0.8.0 — M7 Metadata Enrichment

- Optional Open Library metadata for books, with manual match review and confirmation before saving ISBN links.
- On-demand cover downloads. Downloaded artwork and linked metadata are retained when External Metadata is turned off.
- Improved search and book details, with copyable diagnostics.
- Some linked editions may show Cover unavailable when there is no usable cover reference.

Windows x64, build 2. The release candidate passed the reader resume check, and the stable build launched with the expected version.
