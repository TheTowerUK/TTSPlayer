## Milestone objective

Optional external metadata enrichment for personal libraries — posters, descriptions, cast/creators, genres, and richer detail surfaces — while **local files and catalogue remain authoritative**.

## Explicit exclusions (M7)

| Exclusion | Notes |
|---|---|
| Mandatory online metadata | App must work fully offline without providers |
| Writing provider data into `catalog.json` | ADR-028 |
| Simultaneous video + music + book + comic providers | One vertical slice first (books) |
| Backend bulk enrichment (default) | Deferred; optional stretch |
| Multi-device enrichment sync | M8 |
| M5 deferred music features | Separate backlog |
| Mobile release | M8 |

## Provider evaluation gate

**Complete (Phase 7.2A, 2026-07-30):** [Open Library](https://openlibrary.org/developers/api) selected for the books vertical slice.

→ [books-metadata-provider-evaluation.md](../architecture/books-metadata-provider-evaluation.md) · [m7-phase-7.2-plan.md](../roadmap/m7-phase-7.2-plan.md)

**Rejected primary:** Google Books API (persistence/terms conflict), Library of Congress JSON API (coverage), WorldCat (institutional).

**Future secondary:** ISBNdb (paid API key, user opt-in).
