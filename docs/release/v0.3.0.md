## Highlights

### Dashboard

- **Welcome header** with Live NAS / Demo source chip and catalogue path
- **Overview panel** — total items, library count, largest library, last scan time and duration
- **Continue Watching** — in-progress items with resume position; live refresh after playback
- **Recently Added** — newest indexed items (requires rescan with indexer 0.3.3+ for `added_at`)
- **Featured Folders** — catalogue-ranked subfolders (not user-curated collections)
- **Libraries** — top-level folders from your filesystem layout
- **Recent activity** — scan history from adjacent `scan.history.json`
- **Storage status** — media root, UNC path, and catalogue location
- Unified vertical scroll with visible scrollbars on horizontal carousels

### Browsing & discovery

- Folder-tree navigation mirroring the real filesystem (`FolderScreen` → `ItemDetailScreen` → `PlayerScreen`)
- **Global search** across the loaded catalogue (Ctrl+F from dashboard)
- **Library Manager** for configured media roots and scan targets
- Scoped library rescan preserves folder context after partial scans

### Artwork & cards

- Shared design system: `AppColors`, `AppTypography`, `AppSpacing`, `AppCardStyles`
- `ArtworkService` — sidecar posters, folder artwork, neutral placeholders on failure
- Premium cards: `LibraryCard`, `TtsFolderCard`, `TtsMediaCard`, Continue Watching hero cards
- Artwork sidecars excluded from media listings beside video files

### Playback

- Video playback via `media_kit` on Windows (`.mp4`, `.mkv`, `.mov`, `.m4v`, `.avi`)
- Resume position remembered per item (`shared_preferences`)
- Preflight, timeout, and error recovery on the player screen

### Scanner & catalogue

- Folder-tree indexer with atomic catalogue writes
- Full scan and per-library rescan
- Item `status` field (`available`, `unavailable`, `missing`, …)
- Optional `added_at` timestamp preserved across rescans
- Image extensions indexed (`.jpg`, `.png`, `.webp`, …) for future library types

### Desktop polish

- Keyboard: **Ctrl+F** search, **Escape** back
- Visible scrollbars on dashboard carousels
- Card hover and press effects
- Focus ring and semantics on interactive dashboard cards

## Known limitations

| Area | Limitation |
|---|---|
| **Platform** | Windows only in this release; no Android/iOS builds |
| **Network** | Local paths and UNC only — no HTTPS catalogue or remote streaming |
| **Recently Added** | Empty until catalogue is rescanned with indexer 0.3.3+; bundled demo has no `added_at` |
| **Metadata** | No TMDB or external metadata; title comes from filename / catalogue |
| **Thumbnails** | No server-side thumbnail generation; sidecar images and placeholders only |
| **Organisation** | No user Favourites, Watch Later, or curated Collections |
| **Content types** | Video-first UX; images are indexed but use the same folder browse flow |
| **Settings UI** | Paths configured via `ttsplayer.config.json`, not an in-app settings screen |
| **Search** | Title/filename only — no filters, sort controls, or faceted search |

These are intentional M3 boundaries. See [M4 roadmap](../roadmap/m4-rich-media-libraries.md) for image-library work.

## Upgrade from v0.2.0

1. Replace the indexer script (or rebuild the container) — scanner version **0.3.3**
2. Run a **full rescan** to populate `added_at` and refresh artwork sidecar rules
3. Replace the Windows client build
4. Existing resume positions in `shared_preferences` are preserved

No catalogue schema migration required — `added_at` is optional and backward-compatible.
