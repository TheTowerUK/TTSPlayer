# Screenshots

Add PNG captures here for the root [README.md](../../README.md). Recommended resolution: 1920×1080 or native window size; keep files under ~500 KB where possible.

## Suggested captures

| Filename | What to show |
|---|---|
| `dashboard.png` | Home dashboard — libraries, Continue Watching, storage status |
| `folder-grid.png` | Folder browse grid with artwork placeholders or sidecars |
| `player.png` | Full-screen video playback mid-stream |
| `settings-providers.png` | Settings → catalogue paths, HTTPS URLs, access mode |

## How to capture (Windows)

1. Run `flutter run -d windows` from `client/ttsplayer`.
2. Load a real or demo catalogue; navigate to each screen.
3. Save PNGs into this folder with the names above.
4. Uncomment the image block in the root `README.md` **Screenshots** section.

No screenshots are committed yet — the app UI is easier to capture from a live run than from mock assets.
